# 观点长文写稿规范

## 篇幅与结构

- **2500–3500 字**，移动端阅读约 8–12 分钟。
- 开头 `> 引言金句`：一句有张力的判断句，**禁止原样复述外标题的关键词**。
- 前言 2–3 段：从一个具体的人物场景/原话切入，再抛出 1–2 个待回答的问题。
- 正文 5–6 个 `##` 章节 + 1 个结语章；**每章只讲一个机制**，章内不岔开主题。
- 结尾留可执行的自检清单或行动项，不空喊口号。

## 证据要求

- 每篇 ≥3 条可核查证据，格式偏好：**机构名 + 数字**（如「Multitudes 跟踪五百多名开发者，非工作时间提交上升 19.6%」）。
- 具名人物的原话要保留引号，比转述有力。
- 反直觉的数字优先放（如 METR 的"实际慢 19%、自认快 20%"）。
- 有反方证据时必须给，放在靠后的章节——这决定文章的说服力上限。
- 不确定的研究（预印本、小样本）在文中标注来源性质，不要把争议结论写成定论。

## 语言风格

- 短句为主，一段 3–5 句；判断句独立成段，不要埋在长句里。
- 术语首次出现给通俗解释，第二次直接使用。
- 中文全角标点；英文人名、机构名、专名保留原文。
- 不使用 emoji 分段（正文里的 emoji 只出现在组件自带标签里）。
- 章节标题 8–14 字，能独立表达一个判断，如「神经层面：监督态与心流互斥」。

## 章节节奏模板

1. **现象章**：谁说了什么 / 发生了什么（故事 + 数据）
2. **机制章**：心理学或经济学解释（配数据卡）
3. **拆前提章**：逐条拆掉一个被滥用的概念（编号列表 + 金句）
4. **数据章**：把数字摆成一道无法辩驳的题（表格 + 居中金句）
5. **硬科学章**：生物学/神经层面的终局解释（金句块）
6. **出路章**：反证 + 可执行方法（编号列表 + 提示条）
7. **结语章**：回到开头，给自检清单

不是每篇都要走满 7 步，但**"现象 → 机制 → 反证 → 方法"的骨架不能缺**。
