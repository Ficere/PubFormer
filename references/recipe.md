# 红白色系 · 观点深度分析 固定配方

本文件是 `gzh-opinion-article` 排版的唯一配方来源。组件 HTML 一律从 gzh-design 的
`references/theme-red-white.md` 与 `references/common-components.md` 取，本文件只规定**用什么、用在哪、用多少**。

## 骨架顺序（严格按此装配）

| 顺序 | 组件 | 规格 |
|---|---|---|
| 1 | 引言卡（组件 2） | 白底红色光晕；金句里 2 个关键词用红底白字；**署名行删掉**（作者未知） |
| 2 | 前言正文 | 组件 6 段落 2–3 段，包在 `padding:0 10px` 的 section 里 |
| 3 | 人物/数据引语 | 组件 8b 浅红背景引用块，1 个 |
| 4 | 导读三看点（组件 3） | 红底白字 01/02/03 + 13 字以内看点短语 |
| 5 | 章节 01–05（组件 5） | 首章 `margin-top:16px`，后续 `margin-top:48px`；章间插组件 4 红色渐变分割线 |
| 6 | 结语章 | 编号 `∞`，英文标签 `THE END` |
| 7 | END 分割线（组件 15） | 全文唯一 |
| 8 | 签名区（组件 16） | `{{作者名}}` + `{{一句话简介}}` 占位；名片图 section 删掉 |

## 章内组件分配

| 章节角色 | 核心组件 | 点缀 |
|---|---|---|
| 机制章（讲原理） | 正文 6 + 数据卡 12（三列） | 浅红引用 8b |
| 拆前提章（逐条反驳） | 编号列表 11a（3 项） + 金句 8a | 概念标签 7b |
| 数据章（摆数字） | 表格 12 + 居中金句 8d | 荧光笔 7e |
| 生物学/硬科学章 | 正文 6 + 金句 8a | 概念标签 7b |
| 出路章（给方法） | 编号列表 11a（4 项） + 红色提示 9a | — |
| 结语章 | 编号列表 11a（自检清单） + 居中金句 8d | — |

## 章节英文标签

按章节性质取，全部大写、2 个词以内：

`THE MECHANISM` / `THE DEFINITION` / `THE MATH` / `THE NEUROSCIENCE` / `THE EVIDENCE` / `THE WAY OUT` / `THE END`

## 标记层策略

- **淡粉下划线 7d**（`border-bottom:2px solid #FECACA;font-weight:600;`）：每段 1–3 处，标核心判断句、关键数据、带引号的体感描述、专有名词。
- **概念标签 7b**（浅红底深红字）：只给真正的术语，如「可变比率奖励」「注意力残留」「短暂性前额叶低下」「元专注」，全文 2–4 个。
- **红色加粗 7a**：只给全文最重的结论，≤5 处，例如「感觉高效和真的高效是两种不同的体验」「你不是指挥者，你就是那个瓶颈」。
- **金句块 8a**：放名人原话或自己提炼的判词，全篇 2 处。

## 表格用法

只用于「数字 ↔ 来源」两列对照，表头红底白字、偶数行浅红底，行数 4–6 行。
不要用它做观点对比——那种用编号列表或数据卡更好读。

## 数据卡用法

三列版优先（数字 24px 红色 + 11px 灰色说明），说明文字控制在 20 字内。
一组最多 3 张卡，全篇只用一组，放在第一个机制章的结尾作为"这不是个例"的证据收束。

## 署名与占位

- 签名区固定两句：`我是 {{作者名}}，{{一句话简介，如：热衷于分享 AI 观察与干货}}。` + 三连引导句。
- 无真实名片图时删除图片 section，不留占位。
- 交付时明确提示用户替换这两个占位符。
