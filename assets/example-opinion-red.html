停不下来的不是心流，是 可变比率奖励 ；疲惫的也不是编程，是 监督负荷 。

Steve Yegge，那位常年鼓吹 AI 让生产力翻十倍的资深博主，最近写了篇文章叫《The AI Vampire》。他说 AI 编程 “真诚地让人上瘾” ，长时间 session 之后会突然断电式睡着，并且后悔自己给行业树立了不切实际的标准。

“它同时令人满足、挫败和兴奋。它像打折促销一样发放多巴胺和肾上腺素。很多人把它比作 老虎机 ——你每发一次 prompt 就拉一次拉杆，得到随机奖励，偶尔还有惊人的“赔付”。

LeadDev 采访的一批工程师说法更直白：不是被要求加班，是 “自己从电脑前起不来身” 。一位写了十二年代码的老程序员这样描述自己的日常：Claude 开始“思考”，他按下 Alt+Tab 刷 Twitter；过了一会儿答案出来，代码也跑通了，心里却只有一句“哦，行吧”——就像在 TikTok 上无意识刷视频，有点爽，但很廉价。

于是有两个问题浮出来： 用 coding agent 到底能不能进入心流？这种停不下来的感觉，和刷短视频是一回事吗？ 把心理学、组织行为学和神经科学三套独立的证据放在一起看，答案相当一致，而且比直觉更残酷。

01

THE MECHANISM

老虎机进了 IDE

先说成瘾机制。行为心理学里最强的强化程序叫 可变比率奖励 （Variable Ratio Schedule）：奖励在不可预测的次数后出现，产生最高的反应频率和最强的抗消退性。赌场靠它，短视频靠它——现在整个 AI 编程行业也运行在它上面。

关键在“可变”两个字。如果每次 prompt 都产出完美代码，这个循环只会令人满足，不会令人强迫。正是那种 “有时一次跑通、有时要修三轮、有时彻底崩掉” 的不确定性，让人不停地说“再来一次”。神经科学上这叫多巴胺预测误差：意外奖励触发的神经元放电，比预期中的奖励强得多。

几个数字可以说明这不是个例体感：

19.6%

Multitudes：AI 使用后非工作时间提交上升

持平↓

Faros：个体快 20–40%，组织 DORA 指标持平或变差

40pp

METR：实际慢 19%，自认快 20% 的感知差

最后一个数字值得单独说： 感觉高效和真的高效，在神经层面是两种不同的体验 ，而 AI 编程工具恰好极其擅长触发前者。


02

THE DEFINITION

心流的三个前提，被逐条拆掉

有人会说：快就是好事，我沉浸其中，这不就是心流吗？Csikszentmihalyi 给心流下过三个结构性条件： 明确的目标、清晰的表现反馈、技能与挑战的匹配 。fast.ai 今年那篇《Breaking the Spell of Vibe Coding》逐条对照，结论是 vibe coding 三条全部违反。

1

反馈线索失真。代码跑通了不等于做得好。fast.ai 借用了赌博研究里的概念——“伪装成赢的输”（Loss Disguised as a Win）：多行老虎机让你押二十分返十五分，净亏五分，却播放庆祝音效。AI 一次吐出两百行“基本能用”的代码，是同一个结构。

2

技能-挑战匹配被抽空。心流要求高技能对高挑战，但 vibe coding 里承受挑战的是模型，不是你。你在拉拉杆，机器在玩游戏。

3

虚假的掌控感。你指定了要什么，于是把结果归因为自己的能动性——就像轮盘赌玩家发展出一套“预测转轮”的复杂系统。

Csikszentmihalyi 本人在 2014 年的访谈里预留了判词，他称之为“垃圾心流”（junk flow）：

「对一种肤浅体验上瘾，它起初像心流，后来变成让你上瘾、而不是让你成长的东西。」


03

THE MATH

一道数学题：注意力残留

接下来回答那个更微妙的疑问：任务下发给 agent 之后，人在多个任务之间来回切换，这种短时注意力切换，是不是根本进不了心流？你的直觉是对的，而且有一道几乎不需要辩论的数学题。

2009 年，明尼苏达大学的 Sophie Leroy 发表了后来被引用无数次的论文，提出 注意力残留 （Attention Residue）：从任务 A 切到任务 B 时，若 A 尚未完成，部分认知资源会留在 A 上，你在 B 上的表现 可测量地下降 ，残留持续 15–25 分钟。再叠加另外几个数字：

数字 来源
每 11 分钟切换一次任务 Gloria Mark，UC Irvine
屏幕焦点 47 秒切换一次 Gloria Mark
打断后 23 分 15 秒才回到原任务 Microsoft Research
切换成本最高吞噬 40% 生产性时间 美国心理学会
心流需 10–15 分钟不间断专注才能建立 心流研究综述

每 11 分钟切一次、每次残留 15–25 分钟——心流所需的启动窗口，在数学上不可能存在。

并行跑七个 agent，只是把这个频率再乘一遍。更糟的是那个 30 秒到几分钟的等待窗口——它恰好落在 “足以打断心流、又不足以做任何正事” 的致命区间。于是你去刷手机，或者看另一个 agent 的终端，形成自我打断。研究显示，自我打断比外部打断伤害更大。


04

THE NEUROSCIENCE

神经层面：监督态与心流互斥

以上还是心理层。真正釜底抽薪的一层在生物学： 监督 agent 所需的脑状态，和心流的脑状态，是方向相反的。

神经科学家 Arne Dietrich 把心流的核心机制命名为 短暂性前额叶低下 （Transient Hypofrontality）：深度心流时，负责自我监控、自我批评和时间感的前额叶区域代谢活动降低，资源转向任务相关回路。神经化学的启动序列是：挑战 → 蓝斑释放去甲肾上腺素 → 技能投入 → 多巴胺 → 持续投入 → 内源性大麻素 → 前额叶解除监管。

而监督 agent 是什么状态？你要持续做接受或拒绝的微决策、在 AI 与人类两种思维模式间维持上下文、判断“这个看起来对但对不对”——这恰恰是 心流要关闭的那个模块被要求满负荷在线 。所以问题不是“切换打断了心流”：只要你在监督，心流的神经序列就启动不了——启动链条的第一环，挑战触发去甲肾上腺素释放，就没发生，因为承受挑战的不是你。

「不是切换打断了心流，而是只要你在监督，心流的神经序列就根本启动不了。」

再叠加代谢层的证据：Wiehler 等人的研究表明，持续高需求认知工作会让外侧前额叶皮层 谷氨酸累积 ，使执行控制的激活成本越来越高。这不是意志力问题，是神经化学。BCG 与加州大学河滨分校的数据吻合：高监督需求使精神疲劳上升 12%、信息过载上升 19%。

容量上限同样无情：Cowan 修正了米勒定律，工作记忆的真实容量是 3–4 项，不是 7±2。当一个人同时监督七到十个 agent，每一个都在独立地撞上“需要人类判断”的时刻—— 你不是指挥者，你就是那个瓶颈。


05

THE WAY OUT

一条反证，四条出路

公平起见，也要说另一面的证据。Wake Forest 大学的 Anthony Sali 用 fMRI 和 EEG 研究任务切换，发现认知灵活性的代价取决于切换的任务性质，而非切换本身：在 同一个评估模式内移动 （都是“审查输出”），和在两个无关的执行上下文之间跳转，大脑反应不同。监督模式干扰较小，因为它不需要在工作记忆里维持相互竞争的执行上下文。由此衍生的 元专注 （meta-focus）框架主张：把执行彻底外包，只对“监督质量本身”保持持续注意——这不是多任务，是更高抽象层级的单任务。它有四条具体做法：

1

时间盒审查，而非执行。以前你限定“写代码写多久”，现在限定“审 agent 产出审多久”——二十分钟一个审查块，然后离开。

2

批量审查，不做流式审查。把 N 次微决策合并成一次完整的 review，而不是边生成边判断——持续的评估流会一遍遍触发同一个微决策回路。

3

用固定 checklist 降低切换成本。审多个 agent 产出时用同一套框架：正确性、测试覆盖、安全、符合 spec。评估框架保持稳定，切换的代价就低。

4

风险分级自动审批。低风险操作自动放行，高风险才升级到人——这条是从源头减少打断次数，而不是训练你在打断之间跳得更快。

💡 核心原则只有一句话：把约束从“我的承诺”转移到“流程的不可能性”——承诺对抗不了多巴胺，流程可以。

结语：五个自检信号

2025 年 2 月，Andrej Karpathy 在洗澡时随手造了“vibe coding”这个词。一年后他公开收回它，换成“agentic engineering”，理由是 “要强调这里面有技艺、科学和专业积累” 。造词的人自己认出了陷阱，这大概是最好的注脚。

最后留五个自检信号， 中三条以上，你今天不是在造东西，是在刷 ：

1

说不清今天产出的是什么，只能说“跑通了”；

2

一整天没 commit，或者全盘自动接受、没读 diff；

3

关掉 agent，画不出这个模块的骨架；

4

结束后不是充实，是刷了三小时短视频的那种空虚；

5

你其实在用它逃避一个更难的真实问题——架构决策，或者需求澄清。

停不下来的属于可变比率强化，散架般的疲惫属于监督负荷——两者同时发生，正是它最容易被误读成“心流”的原因。
